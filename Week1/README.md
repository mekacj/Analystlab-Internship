# Telco Customer Churn Analysis - AnalystLab Africa Week 1

## Project Overview

The case study investigates customer Churn for **ABC Communication Ltd** and  uses customer-level telecom data to identify high-risk segments, understand retention patterns, and develop practical business recommendations.

## Business Questions

The analysis addresses:

1. What does the customer base look like?
2. Which customer segments have the highest churn?
3. Does contract type influence retention?
4. Does tenure affect loyalty?
5. Which services are associated with churn?
6. Which payment methods have higher churn?
7. What actions should management take?

## Important Analytical Note

The findings in this project are **descriptive relationships**, not proof of causation. A segment with higher churn should be prioritised for investigation and testing rather than assumed to be the direct cause of churn.
