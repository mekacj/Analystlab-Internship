# HealthConnect Clinic — Week 4 Data Analytics

## Project Overview

This project was completed as part of the **AnalystLab Africa Experience Lab — Week 4 HealthConnect Clinic project**.

The Data Analytics track focuses on understanding appointment attendance and no-show patterns and establishing an analytical foundation for future project stages.

For the Data Analytics track, the project focuses on:

- Understanding the appointment dataset and data dictionary
- Assessing data quality
- Identifying variables associated with attendance and no-shows
- Defining business questions
- Developing meaningful KPIs
- Performing structured analysis with SQL
- Communicating findings through Power BI
