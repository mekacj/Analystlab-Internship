# Superstore Sales Performance Dashboard — AnalystLab Africa Week 2

## Project Overview

This project was completed as part of the **AnalystLab Africa Data Analytics Internship — Week 2**.

The assignment focused on **Business Intelligence and Interactive Dashboard Development** using Microsoft Power BI.

The business scenario is a national retail company that needs an executive dashboard to monitor sales performance, profitability, customer behaviour and regional performance.

## Business Questions

The dashboard is designed to answer:

1. What is the overall sales performance of the company?
2. Which regions generate the highest sales and profit?
3. Which customer segments contribute the most revenue?
4. Which product categories perform best?
5. Which products are the most profitable?
6. What trends can be observed over time?
7. What recommendations should management implement to improve business performance?
